We are going to create a simple database of students and their grades. Students will be associated with a name, unique ID number, and a list of grades. For example, a student named Ben Franklin with ID number 12345 and grades 90, 85, and 88 can be represented with a dictionary as follows:
\begin{minted}{python}

\end{minted}
You will make a class called \texttt{Gradebook} that will contain a list of students and have the following methods:
\begin{itemize}
    \item \texttt{add\_student(name, id)}: This method will add a new student to the gradebook with the given name and ID number. The new student should have an empty list of grades.
    \item \texttt{add\_grade(id, grade)}: This method will add a grade to the list of grades for the student with the given ID number. If no student with that ID exists, print an error message.
    \item \texttt{get\_average(id)}: This method will return the average grade for the student with the given ID number. If no student with that ID exists, print an error message and return None. If the student has no grades, return None.
    \item \texttt{get\_class\_average()}: This method will return the average grade for all students in the gradebook. If there are no students or if no students have grades, return None.
    \item \texttt{get\_student(id)}: This method will return the student dictionary for the student with the given ID number. If no student with that ID exists, print an error message and return None.
\end{itemize}
