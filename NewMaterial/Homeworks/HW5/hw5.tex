\section*{Problem 1: Collecting Data via Google Forms (50 points)}
Generate a Google Form that collects the following data from each respondent:
\begin{itemize}
    \item State of residence prior to attending Penn
    \item Preferred fast food, selected from a list of the following options:
    \begin{itemize}
        \item McDonald's
        \item Burger King
        \item Wendy's
        \item Chick-fil-A
        \item Taco Bell
        \item In-N-Out
        \item Culver's
    \end{itemize}
\end{itemize}
Ask 5 different people from outside this class to fill out your form. Prioritize asking people from different states to get a more diverse dataset. Take a screenshot of your Google Form once you have created it.
