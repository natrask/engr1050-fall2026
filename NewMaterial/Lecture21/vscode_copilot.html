VS Code and AI Coding Assistants

⚠️ For this course, you will never be required to spend any money on AI. The free Gemini in Google Colab is sufficient to do the exercises. The resources provided here are only for those who want some guidance on how to get a modern setup on their own machine. It is likely that this will take some 1-1 guidance to help debug.

In lecture we used Gemini inside Colab. Most working engineers write code in a desktop editor instead, and the most common one is Visual Studio Code (VS Code). It is free, it runs Python and Jupyter notebooks on your own laptop, and it has an AI assistant, GitHub Copilot, built in.

This guide has four parts: install VS Code, install the extensions, get the free student version of Copilot, and a list of the AI tools Penn provides or subsidizes. Start Part 3 today even if you do nothing else, because GitHub takes a few days to approve student applications.

Part 1: Install VS Code

Windows

  1. Go to code.visualstudio.com/download and click the big Windows button. A file whose name starts with VSCodeUserSetup and ends in .exe downloads.
  2. Open the file from your browser's download panel, or from the Downloads folder in File Explorer.
  3. Click I accept the agreement, then Next on each screen, leaving the default choices alone. On the Select Additional Tasks screen, make sure Add to PATH is checked (it is by default).
  4. Click Install, then Finish. VS Code opens.

Mac

  1. Go to code.visualstudio.com/download and click the big Mac button. A .zip file downloads.
  2. Open Finder and click Downloads. Double-click the zip file if it was not unzipped automatically. You now have an app called Visual Studio Code.
  3. Drag Visual Studio Code onto Applications in the Finder sidebar. If you skip this, the app runs out of your Downloads folder and will not update properly.
  4. Open Applications and double-click Visual Studio Code. When macOS warns that it was downloaded from the internet, click Open.

Both: set up Python

  1. VS Code is only an editor; it needs Python installed to run anything. If you have never installed Python on this laptop (Thonny brings its own copy, which VS Code does not use), download it from python.org/downloads and run the installer.
    • Windows: on the first installer screen, check Add python.exe to PATH before clicking Install Now.
    • Mac: click through the installer with the default choices.
  2. Install the Python and Jupyter extensions (Part 2, steps 1–3), then come back here.
  3. Test it: File → New File, choose Python File, type print("Hello from VS Code!"), save it as hello.py, and click the triangle ▷ in the top right. The output appears in the terminal panel at the bottom. If VS Code asks you to Select Interpreter, pick the Python you just installed.

Part 2: Install the extensions

Extensions are add-ons that teach VS Code new tricks. They all install the same way, from inside VS Code.

How to install any extension

  1. Click the Extensions icon on the left edge of the window (four small squares, one of them tilted), or press Ctrl + Shift + X (Windows) / Cmd + Shift + X (Mac). A search box opens at the top of a side panel.
  2. Type the extension's name into the search box. Several results appear. Check the publisher name printed under each result and pick the one from the publisher listed below; copycat extensions with similar names exist.
  3. Click the blue Install button. If VS Code asks whether you trust the publisher, click Trust Publisher & Install. When it finishes, the button changes to a gear icon. If an extension says it needs a reload, click Reload or restart VS Code.

Part 3: Get GitHub Copilot free as a student

Copilot is not a Penn license. It comes from GitHub, which gives it free to verified students through GitHub Education. Your Penn email is how you prove you are a student.

  1. If you do not have a GitHub account, create one at github.com/signup. You can use a personal email; you will add your Penn email next.
  2. Add your Penn email to the account: go to github.com/settings/emails, add your @upenn.edu (or @seas.upenn.edu) address, and click the verification link GitHub sends to it.
  3. Go to github.com/settings/education/benefits and click Start an application. Choose Student, select University of Pennsylvania, and follow the prompts. GitHub may ask you to upload a photo of your PennCard and to let the browser share your location; do both, since these are the most common reasons applications are rejected.
  4. Wait for an approval email. This can take anywhere from minutes to several days.
  5. Once approved, return to the benefits page, find Copilot under the free developer resources, and follow the prompts to activate Copilot Student.

Never pay for anything. If GitHub shows you a trial, a "Free" plan, or a checkout page instead of Copilot Student, your approval has not finished going through. Wait a few days and check github.com/settings/copilot again. While you wait, you can use Copilot Free (no verification needed, limited to 2,000 completions a month) with the same steps below.

Turn Copilot on in VS Code

  1. Make sure the GitHub Copilot Chat extension is installed (Part 2). Open the chat panel with View → Chat, or click the Copilot icon at the top of the window.
  2. Click Sign in and choose GitHub. Your browser opens; log in to the GitHub account you used above and click Authorize. Switch back to VS Code.
  3. Open your hello.py and start typing a comment such as # plot sin(x) from 0 to 2 pi, then press Enter. Gray "ghost text" appears suggesting code. Press Tab to accept it or keep typing to ignore it.
  4. In the chat panel, you can ask questions about your code in plain English, e.g. "why does this give an IndexError?"

If gray suggestions appear while you type, Copilot is working. To turn suggestions off (for example, while practicing for an exam, where you will not have it), click the Copilot icon in the bottom status bar and disable completions. Turn it back on the same way.

What the student plan includes: unlimited code completions, plus a monthly allowance of credits for chat and agent features. You cannot pick the model; Copilot chooses one automatically. GitHub re-checks student status every month, so keep your Penn email on your account.

Things that go wrong, and what to do

My GitHub Education application was rejected

The usual causes are a Penn email that was never verified on the account, a blurry or cropped PennCard photo, or not allowing location sharing. Fix whichever applies and reapply.

Copilot says I don't have access, or asks me to pay

Your student approval has not reached Copilot yet. Do not buy anything. Wait a few days, then check github.com/settings/copilot. In VS Code, make sure you are signed in with the same GitHub account you used to apply (click the person icon at the bottom left).

The triangle run button is missing, or VS Code says no Python interpreter was found

Install the Python extension from Part 2, then press Ctrl + Shift + P (Windows) / Cmd + Shift + P (Mac), type Python: Select Interpreter, and choose the Python you installed. If nothing is listed, restart VS Code after installing Python.

PennChat won't load

You are probably off campus without the VPN. Connect to GlobalProtect, or use AirPennNet on campus.

If you are stuck on anything not listed here, do not spend an hour on it. Ask the person next to you or bring the laptop to office hours.
