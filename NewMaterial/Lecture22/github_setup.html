GitHub Accounts at Penn

Everything on this page is free. You never need to pay GitHub anything for this course. If a page asks for a credit card, stop and go back.

Your final project is shown off on a website hosted on GitHub. GitHub is where most engineers keep their code, and a public project page is a good start to a portfolio you can point internship recruiters to.

This guide has four parts: make a GitHub account, join Penn's GitHub organization with your PennKey, claim the free student benefits, and publish your project website. Do Parts 1–3 today, because the student-benefits approval in Part 3 can take a few days.

Part 1: Make a GitHub account

If you already have a GitHub account, skip to Part 2 and use that one. One account is all you need, for this course and after.

  1. Go to github.com/signup.
  2. Email: we suggest a personal email you will still have after graduating, since this account can follow you for your whole career. You will add your Penn email as a second address in Part 3.
  3. Username: this appears in your website's address (username.github.io), so pick something you would be happy to put on a resume. Penn suggests your PennKey name; if it is taken, try yourpennkey-upenn (for example bfrankln-upenn).
  4. Choose a password, solve the puzzle, and enter the code GitHub emails you. If GitHub asks you to pick a plan, choose Free.

Turn on two-factor authentication

Penn requires two-factor authentication (2FA) on any account that joins its GitHub organization, and GitHub requires it of most accounts anyway.

  1. Click your profile picture (top right) → Settings → Password and authentication, or go straight to github.com/settings/security.
  2. Click Enable two-factor authentication. The simplest option is an authenticator app on your phone (Duo Mobile, which you already use for PennKey, works; so do Google Authenticator and Microsoft Authenticator). Scan the QR code with the app and type in the 6-digit code it shows.
  3. Save your recovery codes when GitHub shows them: download them and keep them somewhere other than your phone. If you lose your phone without them, you can be locked out of the account for good.

GitHub's full instructions: Configuring two-factor authentication.

Part 2: Join Penn's GitHub organization

Penn is part of the GitHub Campus Program, run by Penn's Information Systems & Computing (ISC). Members of the Penn community link their GitHub account to their PennKey and join Penn's upenn organization on GitHub. You keep your own account; joining connects it to Penn.

  1. Log in to GitHub (with 2FA turned on, from Part 1).
  2. In the same browser, go to github.com/orgs/upenn/sso/sign_up.
  3. You are sent to the usual Penn WebLogin page. Log in with your PennKey and approve the Duo prompt.
  4. GitHub brings you back and adds you to the upenn organization. To check, open github.com/settings/organizations; upenn should be listed.

Your PennKey can be linked to only one GitHub account at a time. If you have more than one GitHub account, link the one you plan to keep.

Penn's official page for the program: github.isc.upenn.edu. You may see GitHub Copilot listed there as a paid Penn service. You do not need it; Part 3 gets you Copilot free.

Part 3: Claim the free student benefits

Separately from Penn, GitHub gives verified students GitHub Education benefits for free: GitHub Pro, Copilot Student (the AI assistant from the VS Code guide), and the Student Developer Pack of free tools from other companies. Your Penn email is how you prove you are a student.

  1. Add your Penn email to your account: go to github.com/settings/emails, add your @upenn.edu (or @seas.upenn.edu) address, and click the verification link GitHub sends to it. Leave your personal email as the primary address.
  2. Go to github.com/settings/education/benefits and click Start an application. Choose Student, select University of Pennsylvania, and follow the prompts. GitHub may ask for a photo of your PennCard and for permission to see your location; allow both, since missing them is the most common reason applications are rejected.
  3. Wait for the approval email. It can take anywhere from minutes to several days. You do not need to wait for it to do Part 4.

If you already did this for the VS Code guide, you are done with this part.

Part 4: Publish your final project website

GitHub Pages turns a repository (a folder of files on GitHub) into a public website, for free. You can do all of this in the browser; nothing to install.

⚠️ Your website is public. Anyone on the internet can see it. Do not post passwords, other students' grades or personal information, or anyone's face or name in your video without their OK. Penn's GitHub guidance also says GitHub is not a place for sensitive data such as FERPA-protected records.

Create the site

  1. One person in your group does this part. Go to github.com/new.
  2. Owner: your own username (not upenn). Repository name: something short with no spaces, like engr1050-final-project. Set it to Public and check Add a README file. Click Create repository.
  3. In the new repository, click Add file → Create new file. Name it index.html and paste in the starter page below. Click Commit changes, then Commit changes again in the pop-up.
  4. Click Settings (the tab along the top of the repository) → Pages in the left sidebar. Under Build and deployment, set Source to Deploy from a branch, set Branch to main and / (root), and click Save.
  5. Wait a minute or two and refresh the Pages settings. A box appears saying Your site is live at followed by the address, which looks like https://username.github.io/engr1050-final-project/. Open it to check.

Starter page

Copy this into index.html and replace the capitalized parts. Ask Gemini or another AI tool to help you style it; that is fair game.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>PROJECT NAME</title>
</head>
<body>
  <h1>PROJECT NAME</h1>
  <p>By TEAM MEMBER NAMES, ENGR 1050 final project</p>

  <h2>What it does</h2>
  <p>ONE PARAGRAPH DESCRIBING YOUR PROJECT.</p>

  <h2>Demo video</h2>
  <video controls width="640" src="demo.mp4"></video>

  <h2>Components</h2>
  <ul>
    <li>Raspberry Pi Pico</li>
    <li>COMPONENT YOU ORDERED</li>
  </ul>

  <h2>Code</h2>
  <p><a href="main.py">main.py</a></p>
</body>
</html>

Add your video, code, and photos

  1. In the repository, click Add file → Upload files, drag in your files (for example demo.mp4, main.py, photos), and click Commit changes. The names must match what index.html points to.
  2. The site updates a minute or two after each commit. If you don't see your change, refresh with Ctrl + Shift + R (Windows) / Cmd + Shift + R (Mac).

Video too big? The browser upload accepts files up to 25 MB, which is about a minute of phone video. Either shorten or compress the video (most phones can trim and export at a lower resolution), or upload it to YouTube as Unlisted and paste YouTube's Share → Embed code into index.html in place of the <video> line.

Let your teammates edit

In the repository, go to Settings → Collaborators → Add people and enter each teammate's GitHub username. They get an email invitation and must accept it before they can edit.

Things that go wrong, and what to do

The Penn sign-up link says I need two-factor authentication

Finish the 2FA steps in Part 1, then open the sign-up link again.

The Penn sign-up link linked the wrong GitHub account

It uses whichever account is logged in to GitHub in that browser. Log out of GitHub, log in to the account you want, and try again. If it still won't switch, ask in office hours.

My site shows a 404 page

Check that the file is named exactly index.html (all lowercase) and sits at the top level of the repository, not inside a folder; that the repository is Public; and that Pages is set to the main branch. The first deploy can take a few minutes.

My video or picture doesn't show up

File names are case sensitive on the web: Demo.MP4 and demo.mp4 are different files. Make the name in index.html match the uploaded file exactly. If the video still won't play, re-export it as .mp4; iPhone .mov files often don't play in other browsers.

My GitHub Education application was rejected

The usual causes are a Penn email that was never verified on the account, a blurry or cropped PennCard photo, or not allowing location sharing. Fix whichever applies and reapply. Your website does not depend on this approval.

If you are stuck on anything not listed here, do not spend an hour on it. Ask the person next to you or bring the laptop to office hours.
