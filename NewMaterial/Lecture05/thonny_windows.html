Installing Thonny on Windows

Up to now, every line of Python you have written ran in Colab, which means it ran on a computer in a Google data center. To drive a circuit or a robot, the program has to run on your laptop, because your laptop is the thing with a USB cable plugged into the microcontroller. Thonny is a small, free program that runs Python on your own computer. It is the only tool you need for the hardware part of this course.

These directions assume you have never installed a program from the internet before. Nothing here is hard, but there are several steps where the computer will ask you a question, and the directions tell you what to answer. Follow them in order and do not skip any. The whole thing takes about ten minutes.

Using a Mac? Stop here and use the Mac instructions instead. The steps are different.

What you need before you start

  • A Windows laptop (Windows 10 or Windows 11) that you can install programs on. If it is a school-managed laptop that blocks installs, come to office hours.
  • An internet connection.
  • About 200 MB of free disk space.

Part 1: Download the installer

  1. Open a web browser. Any of Edge, Chrome, or Firefox is fine.
  2. Click in the address bar at the top of the browser, type thonny.org, and press Enter.
  3. Near the top right of the page is a box with a Windows logo that says something like Download version 4.x.x for Windows. Move your mouse over that box. A small menu drops down with a few choices.
  4. Click the first choice, which says Installer with 64-bit Python. Do not pick the "portable" or "32-bit" variants.
  5. Your browser will download a file whose name starts with thonny- and ends in .exe. Depending on the browser, you may see a small download panel appear in the top right, or a bar along the bottom. Wait for it to finish. The file is about 25 MB, so this takes a few seconds to a minute.
    • If the browser asks "Do you want to keep this file?" or says the file "isn't commonly downloaded", click Keep. Thonny is safe; the browser says this about any small program it has not seen many times.

Part 2: Run the installer

  1. Open the file you just downloaded. The easiest way is to click on it in the browser's download panel. If you cannot find that, open File Explorer (the yellow folder icon on the taskbar), click Downloads on the left, and double-click the file that starts with thonny-.
  2. You will very likely see a blue box that says Windows protected your PC, with only a Don't run button. This is Windows being cautious about a program it does not recognize. To get past it:
    • Click the small text link that says More info.
    • A new button appears that says Run anyway. Click it.
  3. If a window asks Do you want to allow this app to make changes to your device?, click Yes.
  4. The Thonny setup wizard opens. If it asks whether to install for just me or all users, pick Install for me only. Click Next.
  5. A license agreement appears. Click the circle next to I accept the agreement, then Next.
  6. It asks where to install. Leave the suggested folder alone and click Next.
  7. It asks about a desktop icon. Check the box for Create desktop icon so Thonny is easy to find later, then click Next.
  8. Click Install. A progress bar runs for about a minute.
  9. When it says the setup is complete, click Finish.

Part 3: Open Thonny for the first time

  1. Double-click the new Thonny icon on your desktop. If there is no icon, click the Windows Start button, type thonny, and click the Thonny app that appears at the top of the results.
  2. The first time it opens, a small window asks you to choose a Language and an Initial settings mode. Leave the language as English and the settings as Standard, then click Let's go!
  3. The main Thonny window appears. It has two important areas:
    • The big white area on top, labelled <untitled>, is the editor. This is where you type your program.
    • The area at the bottom labelled Shell is where your program's output shows up. It has a >>> prompt in it.
    If you do not see the Shell, click the View menu at the top and click Shell so it has a check mark.

Part 4: Hello, world

Now you will write and run a one-line program. This proves the install worked and shows you the routine you will use for every program from here on: type, save, run.

  1. Click inside the editor (the big white area on top) and type exactly this, including the parentheses and the quotation marks: 
    print("Hello from my laptop!")
  2. Run the program. Either click the green circle with a white triangle in the toolbar (it is labelled Run current script if you hover over it), or press the F5 key at the top of your keyboard.
  3. Because the file has never been saved, Thonny pops up a Save as window before it runs. Do this:
    • On the left side of the window, click Desktop (or Documents, either is fine, just remember which).
    • In the File name box at the bottom, type hello.py. The .py ending is what marks it as a Python file, so do not leave it off.
    • Click Save.
  4. The program runs right away. Look at the Shell area at the bottom. You should see: 
    >>> %Run hello.py
Hello from my laptop!
>>>

If you see Hello from my laptop! in the Shell, Thonny is working. Take a screenshot of the whole Thonny window showing your code and the output; it is the first half of today's in-class exercise on Canvas. The second half is blinking an LED on the Pico, which the Pico blink tutorial walks you through. To take a screenshot on Windows, press Windows + Shift + S, drag a box around the Thonny window, and the picture is copied to your clipboard. Paste it into the Canvas submission box with Ctrl + V, or open the Snipping Tool app to save it as a file.

Part 5: Try one more thing

Change the program so it does something Colab could not. Replace the contents of the editor with this:

import platform
print("This program is running on", platform.node())
for i in range(3):
    print("count", i)

Press F5 again. This time it will not ask where to save, because the file already has a name. The first line prints the name of your own laptop, which is a nice reminder that the code is running right here and not in Google's basement.

Things that go wrong, and what to do

"Windows protected your PC" and there is no "Run anyway" button

Click the More info link first. The Run anyway button only appears after that.

The download is a file ending in .zip, not .exe

You picked the portable variant. Go back to thonny.org and choose Installer with 64-bit Python.

I typed the program but nothing happens when I press F5

On some laptops the F-keys do volume and brightness unless you also hold the Fn key. Try Fn + F5, or just click the green run button in the toolbar.

The Shell shows red text ending in SyntaxError

Something was typed slightly wrong. Check that you have both parentheses, both quotation marks, and that the word is print in all lowercase. Fix it and press F5 again.

The Shell says NameError: name 'Print' is not defined

Python is case-sensitive. Print and print are different words. Use lowercase.

I saved the file but can't find it again

In Thonny, click File then Open, and click Desktop or Documents on the left, wherever you saved it. Thonny also lists recent files under File → Recent files.

The installer says I don't have permission

Your laptop is probably managed by an organization. Bring it to office hours and we will sort it out together. In the meantime you can still do this exercise on a lab computer.

If you are stuck on anything not listed here, do not spend an hour on it. Ask the person next to you, ask on Ed Discussion with a screenshot of what you see, or bring the laptop to office hours.
