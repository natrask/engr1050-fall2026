Installing Thonny on a Mac

Up to now, every line of Python you have written ran in Colab, which means it ran on a computer in a Google data center. To drive a circuit or a robot, the program has to run on your laptop, because your laptop is the thing with a USB cable plugged into the microcontroller. Thonny is a small, free program that runs Python on your own computer. It is the only tool you need for the hardware part of this course.

These directions assume you have never installed a program from the internet before. Nothing here is hard, but there are several steps where the computer will ask you a question, and the directions tell you what to answer. Follow them in order and do not skip any. The whole thing takes about ten minutes.

Using Windows? Stop here and use the Windows instructions instead. The steps are different.

What you need before you start

  • A Mac running macOS 10.15 (Catalina) or newer. Anything bought in the last several years qualifies.
  • The password you use to log in to the Mac. The installer will ask for it.
  • An internet connection.

Part 1: Download the installer

  1. Open a web browser. Safari, Chrome, or Firefox all work.
  2. Click in the address bar at the top, type thonny.org, and press Return.
  3. Near the top right of the page is a box with an Apple logo that says something like Download version 4.x.x for macOS. Move your mouse over that box. A small menu drops down.
  4. Click the choice that says Installer for macOS 10.15+. There is only one installer and it works on every Mac, whether it has an Intel chip or an Apple chip (M1, M2, M3, and so on). You do not need to check which one you have.
  5. Your browser downloads a file whose name starts with thonny- and ends in .pkg. In Safari, a small downloads arrow in the top right fills in as it downloads. Wait for it to finish, which takes a few seconds to a minute.
    • If Safari asks Do you want to allow downloads on "thonny.org"?, click Allow.

Part 2: Run the installer

  1. Open the file you downloaded. In Safari, click the downloads arrow at the top right and click the file. Otherwise, open Finder (the blue and white smiling face at the left end of the Dock), click Downloads in the sidebar, and double-click the file that starts with thonny-.
  2. An installer window titled Install Thonny opens. Click Continue.
  3. The license appears. Click Continue, and when it asks you to agree, click Agree.
  4. Click Install. Do not change the destination.
  5. A window pops up asking for your password. This is the same password you use to log in to the Mac. Type it and click Install Software. If the Mac has Touch ID, you may be able to use your fingerprint instead.
  6. A progress bar runs for less than a minute. When it says The installation was successful, click Close.
  7. The Mac may ask whether to move the installer to the Trash. Click Move to Trash. You do not need it any more.

Part 3: Open Thonny for the first time

  1. Open Finder, click Applications in the sidebar, and scroll until you find Thonny. Double-click it. A faster way is to press ⌘ Command + Space, type thonny, and press Return.
  2. If the Mac says something like "Thonny" is an app downloaded from the Internet. Are you sure you want to open it?, click Open.
  3. The first time it opens, a small window asks you to choose a Language and an Initial settings mode. Leave the language as English and the settings as Standard, then click Let's go!
  4. The main Thonny window appears. It has two important areas:
    • The big white area on top, labelled <untitled>, is the editor. This is where you type your program.
    • The area at the bottom labelled Shell is where your program's output shows up. It has a >>> prompt in it.
    If you do not see the Shell, click the View menu at the top of the screen and click Shell so it has a check mark.
  5. Optional but handy: right-click (or two-finger click) the Thonny icon in the Dock, choose Options, then Keep in Dock. Now you can open it with one click next time.

Part 4: Hello, world

Now you will write and run a one-line program. This proves the install worked and shows you the routine you will use for every program from here on: type, save, run.

  1. Click inside the editor (the big white area on top) and type exactly this, including the parentheses and the quotation marks: 
    print("Hello from my laptop!")
  2. Run the program by clicking the green circle with a white triangle in the toolbar (hover over it and it says Run current script). You can also use the keyboard: on most Mac keyboards the top row of keys does brightness and volume, so press fn + F5 together, or use ⌘ Command + R.
  3. Because the file has never been saved, Thonny pops up a Save window before it runs. Do this:
    • In the Save As box at the top, type hello.py. The .py ending is what marks it as a Python file, so do not leave it off.
    • In the Where menu, choose Desktop or Documents. Either is fine, just remember which. If the window is small and you do not see a sidebar, click the little down-arrow next to the file name to expand it.
    • Click Save.
  4. The program runs right away. Look at the Shell area at the bottom. You should see: 
    >>> %Run hello.py
Hello from my laptop!
>>>

If you see Hello from my laptop! in the Shell, you are done. Take a screenshot of the whole Thonny window showing your code and the output, and submit it on Canvas for today's in-class exercise. To take a screenshot on a Mac, press ⌘ Command + Shift + 4, then drag a box around the Thonny window. The picture is saved to your Desktop as a file called Screenshot ...png. Upload that file to Canvas.

Part 5: Try one more thing

Change the program so it does something Colab could not. Replace the contents of the editor with this:

import platform
print("This program is running on", platform.node())
for i in range(3):
    print("count", i)

Run it again. This time it will not ask where to save, because the file already has a name. The first line prints the name of your own laptop, which is a nice reminder that the code is running right here and not in Google's basement.

Things that go wrong, and what to do

The Mac says the app "cannot be opened because Apple cannot check it for malicious software"

Click OK or Done to dismiss the message. Then open System Settings (the gear icon in the Dock, or Apple menu → System Settings), click Privacy & Security in the sidebar, and scroll down to the Security section. There will be a line about Thonny being blocked, with an Open Anyway button next to it. Click it, enter your password, and Thonny opens. You only have to do this once. On older Macs the same setting lives in System Preferences → Security & Privacy → General.

The download is a .zip file, or I cannot find a .pkg

Go back to thonny.org and hover over the macOS download box. Click the choice that says Installer for macOS. Do not use the "portable" variant.

Pressing F5 changes my keyboard brightness instead of running the program

That is normal on a Mac. Hold fn while pressing F5, or just click the green run button in the toolbar.

The Shell shows red text ending in SyntaxError

Something was typed slightly wrong. Check that you have both parentheses, both quotation marks, and that the word is print in all lowercase. Also make sure the quotation marks are plain straight quotes; if you typed the line in Notes or Pages first and pasted it, the Mac may have replaced them with curly quotes, which Python does not accept. Retype the quotes inside Thonny.

The Shell says NameError: name 'Print' is not defined

Python is case-sensitive. Print and print are different words. Use lowercase.

I saved the file but can't find it again

In Thonny, click File then Open, and pick Desktop or Documents in the sidebar, wherever you saved it. Thonny also lists recent files under File → Recent files.

If you are stuck on anything not listed here, do not spend an hour on it. Ask the person next to you, ask on Ed Discussion with a screenshot of what you see, or bring the laptop to office hours.
