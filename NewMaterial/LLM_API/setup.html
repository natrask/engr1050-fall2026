Calling an LLM from Python

In class we have used Gemini through the chat panel built into Colab. A Python program can use the same model directly: it sends your prompt to Google's servers as a string and gets the model's reply back as another string. That takes about five lines of code, and once the reply is a string, your program can print it, save it, or test it in an if statement like any other string.

Programs reach the model through an API (application programming interface), which is a set of functions that one program uses to talk to another. To use Google's Gemini API you need an API key, a long password-like string that tells Google which account a request comes from. This page shows how to get a free key, store it safely in Colab, and run a notebook that sends the model a question you type in.

Everything on this page is free. Google's free tier for the Gemini API does not require a credit card.

Before you start

  • You must be 18 or older. Google's terms for the Gemini API require it. If you are under 18, read through the notebook and follow along in class, but do not create a key.
  • Never add billing. If Google AI Studio offers to set up billing, upgrade, or move you to a paid tier, close that page. A key stays on the free tier as long as no billing account is attached to it.
  • Assume Google can read what you send. On the free tier, Google uses your prompts and the model's replies to improve its products, and human reviewers may read them. Do not type passwords, personal information, or anything about other students.

Part 1: Get a free API key

The key comes from Google AI Studio, Google's website for developers who use Gemini from their own code.

  1. Go to aistudio.google.com/apikey and sign in with a Google account. A personal Gmail account works. If AI Studio says it is not available for the account you signed in with, sign in with a personal account instead.
  2. The first time you visit, AI Studio asks you to accept its terms. After you accept, it creates a project and an API key for you. If no key is listed on the page, click Create API key.
  3. Click the copy icon next to your key. Keep this tab open; you will paste the key in Part 2.

Treat the key like a password. Anyone who has it can send requests that count against your account. Never paste it into a notebook cell, an email, a chat with an AI model, or your final project website. Whatever you type into a notebook cell is saved inside the .ipynb file and goes wherever the file goes. If you think your key has leaked, delete it in AI Studio and create a new one.

Part 2: Store the key in Colab Secrets

Colab has a Secrets panel for keys like this one. It stores them with your Google account, outside the notebook file, so the notebook can read the key without the key ever appearing in a cell.

  1. Open the notebook in Colab: llm_api.ipynb. Click File → Save a copy in Drive so your changes are kept.
  2. In the left sidebar, click the key icon to open Secrets.
  3. Click Add new secret. Set Name to GEMINI_API_KEY, spelled exactly like that. Paste your key into Value, and turn on the Notebook access switch.

The secret stays saved for your other notebooks. Each new notebook asks you to turn on access before it can read the key.

Part 3: Run the notebook

  1. Run the first code cell. It reads your key and prints a line saying the client is ready. If Colab asks whether to grant the notebook access to your secret, click Grant access.
  2. Run the next cell. A text box appears under it with the message Please enter a prompt for the LLM:. Type a question and press Enter. The model's reply prints below the cell.

Here is the cell that does the work:

prompt = input('Please enter a prompt for the LLM:')

response = client.models.generate_content(model=MODEL, contents=prompt)

print(response.text)

input pauses the program until you press Enter and returns what you typed as a string. generate_content sends that string to the model named in MODEL and waits for the reply. response.text is the reply as an ordinary string.

The notebook ends with three short extensions you can try: wrapping the call in a function, holding a conversation in a while loop, and giving the model a job description with a system instruction.

Free tier limits

The free tier limits how often you can send requests. When we checked in September 2026, the model the notebook uses, gemini-3.1-flash-lite, allowed 15 requests per minute. Google changes these limits and sets them per account. AI Studio shows the limits on your key at aistudio.google.com/rate-limit.

Things that go wrong, and what to do

An error says the secret does not exist

The name in the Secrets panel must be exactly GEMINI_API_KEY: all capitals, with underscores. Fix the name and run the cell again.

An error says the notebook does not have access to the secret

Open the Secrets panel and turn on the Notebook access switch next to GEMINI_API_KEY, then run the cell again.

400 INVALID_ARGUMENT … API key not valid

The key was probably copied incompletely. Copy it again from AI Studio, paste it over the secret's value, and rerun the first code cell.

429 RESOURCE_EXHAUSTED

You sent more requests than the free tier allows. Wait a minute and try again. If it keeps happening, you have likely used the day's allowance; try again tomorrow. Do not upgrade to a paid tier to get around it.

404 NOT_FOUND, mentioning the model

Google has retired that model. Pick a current Flash-Lite model from Google's model list and change the MODEL line in the first code cell to its name.

AI Studio asks for a credit card

Stop and close the page. Nothing in this tutorial needs one.

If you are stuck on anything not listed here, do not spend an hour on it. Ask the person next to you or bring the laptop to office hours.
