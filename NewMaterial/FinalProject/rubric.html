Final Project Rubric

Final projects will be collected in the form of a website hosted as a GitHub repository.

Start here

  • See the bar: the example project website (“Team Hover”, built from our helicopter labs) follows exactly the format below.
  • Copy it: start your site from the project template. Part 4 of the GitHub setup guide walks through it.
  • Adapt it: the LLM guide has prompts for filling in and restyling the template with a free AI model.

What your project must include

Every project must include some amount of Python code, even if it is a simple loop that runs your circuit.

What your website must include

Each website should consist of three pages:

  1. Overview page. Two bullets summarizing:
    1. the goals of the project, and
    2. what you were able to achieve.
  2. Demonstration of components page.
    1. A description of each component used in the project (for example sensors, motors, datasets, or code).
    2. A sequence of images or videos illustrating each component functioning as expected.
  3. Final demo page.
    1. A short description of what the final demo should be:
      • for a device, describe how your invention functions;
      • if you wrote a program, describe the functionality of the program;
      • if you did some machine learning, describe the prediction you attempted to make.
    2. A video, photos, or screenshots showing the final product performing your desired task.

Grading

PointsCriterion
50 / 100Presentation. The material is presented in the format described above.
50 / 100Technical merit.

No points will be docked for unsuccessful completion of a sufficiently ambitious project, though you must document your partial success on your website.

Submission

Use the Canvas assignment to submit a link to your functional GitHub website.

Due by the end of finals: Thursday, December 17. Check that the link opens your live site in a private or incognito window before you submit.
